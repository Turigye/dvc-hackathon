# Project Assets

Keep only accepted, project-bound visual assets here.

- Use bespoke generated illustrations for non-hero landing-page imagery; do not introduce stock photography.
- Store the final prompt, source/derivative relationship, license note, and responsive dimensions in the adjacent asset manifest when assets are added.
- Prefer AVIF or WebP for opaque raster assets. Use transparent PNG/WebP only when alpha is required.
- Never lazy-load the LCP asset. Supply `sizes` for responsive images and use `next/image` for application imagery.
