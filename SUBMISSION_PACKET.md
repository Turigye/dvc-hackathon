# Submission Packet

## Tip Tap Games draft

- **Project name:** Tip Tap Games
- **Short description (193 characters):** A swipeable one-thumb arcade: hit the beat, survive the slipstream, and remember the stack. Play instantly, chase live ranks, then save or challenge friends when a score hits.
- **Cover image:** `public/assets/tip-tap-cover.png`
- **Repository:** https://github.com/Turigye/dvc-hackathon
- **Why this idea:** It meets the brief through three genuinely different games while keeping the first action instant. The feed makes discovery effortless and ranks create a reason to take one more run.
- **Build approach:** Next.js powers the mobile game feed. Each game is a compact client-side engine; server routes validate score submissions and Supabase stores players, games, and scores when credentials are connected.
- **Tools / agents:** Codex, GPT-5.6, Next.js, Tailwind CSS, Phosphor Icons, Supabase, Vercel, OpenAI image generation.
