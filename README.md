# DVC Hackathon

Preparation workspace for the Dollar Vibe Club live hackathon.

## Start here

1. Read [HACKATHON_CONTEXT.md](./HACKATHON_CONTEXT.md) for event rules, contacts, and submission expectations.
2. Read [AGENTS.md](./AGENTS.md) before changing the application.
3. Complete [design.md](./design.md) once the official live brief is revealed.
4. Use [DESIGN_RESOURCES.md](./DESIGN_RESOURCES.md) to research original design directions.
5. Follow [PERFORMANCE_AND_QA.md](./PERFORMANCE_AND_QA.md) during development and [SUBMISSION_PACKET.md](./SUBMISSION_PACKET.md) before delivery.

## Local development

```bash
pnpm install
pnpm dev
```

## Required checks

```bash
pnpm lint
pnpm typecheck
pnpm build
```

## Stack

Next.js App Router, TypeScript, Tailwind CSS, shadcn-compatible primitives, Phosphor Icons, and Vercel deployment.
